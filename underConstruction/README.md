# underConstruction

This folder contains development-only and historical working artifacts that are **not required to run Merchant Maxx**.

Archived items include:
- `scratch/` — temporary scripts, smoke tests, migration helpers, logs, and verification output.
- `playwright-mcp/` — Playwright MCP development/debug artifacts and snapshots.

These files are retained for reference while the project is under active development, but they are intentionally separated from the production application source tree.
